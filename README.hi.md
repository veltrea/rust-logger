# rust-logger

UNIX मानक `logger` कमांड का एक रस्ट (Rust) कार्यान्वयन, जिसे Windows वातावरण (कमांड प्रॉम्प्ट / PowerShell) में सुरक्षित और विश्वसनीय उपयोग के लिए डिज़ाइन किया गया है। यह स्वचालित रूप से स्थानीय एन्कोडिंग (Shift-JIS/UTF-16) से इनपुट को UTF-8 में बदल देता है और इसे Syslog सर्वर पर भेजता है।

यह टूल **[vlt-syslogd](https://github.com/veltrea/vlt-syslogd)** के साथ सहजता से काम करने के लिए विकसित किया गया था, जो एक Windows Syslog सर्वर है जो UTF-8 का समर्थन करता है और बहुभाषी पात्रों को सही ढंग से प्रदर्शित करता है।

## विशेषताएं

- **UNIX `logger` संगतता**: `-n`, `-P`, और `-p` जैसे मानक विकल्पों का समर्थन करता है।
- **पूर्ण Windows समर्थन**: `cmd.exe` (Shift-JIS) और `PowerShell` (UTF-16) से इनपुट को ठीक से संभालता है।
- **सिंगल बाइनरी**: बिना किसी निर्भरता के स्टैंडअलोन एक्ज़ीक्यूटेबल के रूप में चलता है।

Releases पेज से `rust-logger.exe` डाउनलोड करें और इसे अपने सिस्टम के PATH में शामिल डायरेक्टरी में रखें।

## उपयोग

मूल उपयोग UNIX `logger` कमांड के समान है।

```powershell
# मूल उपयोग (डिफ़ॉल्ट प्राथमिकता user.info है)
rust-logger -n 127.0.0.1 -P 514 "लॉग संदेश मुख्य भाग"

# प्राथमिकता और टैग निर्दिष्ट करना
rust-logger -n 192.0.2.10 -p local0.warn -t MyBatchApp "चेतावनी: प्रक्रिया विफल रही"
```

### विकल्प

| विकल्प | संक्षिप्त रूप | विवरण | डिफ़ॉल्ट |
| :--- | :--- | :--- | :--- |
| `--server` | `-n` | **[आवश्यक]** Syslog सर्वर होस्टनाम या IP | - |
| `--port` | `-P` | गंतव्य पोर्ट नंबर | 514 |
| `--priority` | `-p` | `facility.level` प्रारूप में प्राथमिकता | `user.info` |
| `--tag` | `-t` | टैग (पहचानकर्ता) | `rust-logger` |
| `--encoding` | - | आउटपुट एन्कोडिंग (`utf-8`, `shift_jis`, आदि) | `utf-8` |
| `[MESSAGE]` | - | लॉग संदेश (तर्कों के अंत में) | - |

## रिलीज़ नोट्स

### RFC 5424 बहुभाषी समर्थन सुधार (07/02/2026)
RFC 5424 विनिर्देश से संबंधित कार्यान्वयन बग फिक्स किए गए:
- **MSG फ़ील्ड प्रारूप**: `MSG-UTF8` प्रारूप के लिए `MSG` फ़ील्ड की शुरुआत में सही ढंग से BOM जोड़ा गया।
- **स्वचालित एन्कोडिंग पहचान**: UTF-8 के लिए पैकेट संरचना को `MSG-UTF8` (BOM के साथ) और अन्य के लिए `MSG-ANY` (कोई BOM नहीं) के रूप में कॉन्फ़िगर किया गया।
- **Windows एकीकरण**: रस्ट के तर्क सामान्यीकरण का उपयोग करके `cmd.exe` और `PowerShell` से स्थानीय इनपुट को पारदर्शी रूप से संभालने के लिए आंतरिक संरचना को परिष्कृत किया गया।
