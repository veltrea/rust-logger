# rust-logger

تطبيق بلغة Rust لأمر `logger` القياسي في UNIX، مصمم للاستخدام الآمن والموثوق في بيئات Windows (Command Prompt / PowerShell). يقوم تلقائياً بتحويل المدخلات من الترميزات المحلية (مثل Shift-JIS/UTF-16) إلى UTF-8 وإرسالها إلى خادم Syslog.

تم تطوير هذه الأداة لتعمل بسلاسة مع **[vlt-syslogd](https://github.com/veltrea/vlt-syslogd)**، وهو خادم Syslog لنظام Windows يدعم UTF-8 ويعرض الأحرف متعددة اللغات بشكل صحيح.

## الميزات

- **التوافق مع UNIX `logger`**: يدعم الخيارات القياسية مثل `-n` و `-P` و `-p`.
- **دعم كامل لنظام Windows**: يتعامل بشكل صحيح مع المدخلات من `cmd.exe` (Shift-JIS) و `PowerShell` (UTF-16).
- **ملف تنفيذي واحد**: يعمل كملف مستقل دون الحاجة إلى تبعات إضافية.

## التثبيت

قم بتنزيل `rust-logger.exe` من صفحة الإصدارات (Releases) وضعه في مجلد مدرج ضمن PATH الخاص بنظامك.

## الاستخدام

الاستخدام الأساسي مطابق تماماً لأمر `logger` في UNIX.

```powershell
# الاستخدام الأساسي (الأولوية الافتراضية هي user.info)
rust-logger -n 127.0.0.1 -P 514 "نص رسالة السجل"

# تحديد الأولوية والوسم (Tag)
rust-logger -n 192.0.2.10 -p local0.warn -t MyBatchApp "تحذير: فشلت العملية"
```

### الخيارات

| الخيار | المختصر | الوصف | الافتراضي |
| :--- | :--- | :--- | :--- |
| `--server` | `-n` | **[مطلوب]** اسم المضيف أو عنوان IP لخادم Syslog | - |
| `--port` | `-P` | رقم المنفذ الوجهة | 514 |
| `--priority` | `-p` | الأولوية بتنسيق `facility.level` | `user.info` |
| `--tag` | `-t` | الوسم (المعرف) | `rust-logger` |
| `--encoding` | - | ترميز المخرجات (`utf-8` ، `shift_jis` ، إلخ) | `utf-8` |
| `[MESSAGE]` | - | رسالة السجل (في نهاية المعاملات) | - |

## ملاحظات الإصدار

### إصلاح دعم اللغات المتعددة RFC 5424 (07/02/2026)
تم إصلاح أخطاء التنفيذ المتعلقة بمواصفات RFC 5424:
- **تنسيق حقل MSG**: تمت إضافة علامة BOM بشكل صحيح إلى بداية حقل `MSG` لتنسيق `MSG-UTF8`.
- **الكشف التلقائي عن الترميز**: تم تكوين هيكل الحزمة كـ `MSG-UTF8` (مع BOM) لترميز UTF-8 و `MSG-ANY` (بدون BOM) للترميزات الأخرى.
- **التكامل مع Windows**: تحسين الهيكل الداخلي للتعامل بشفافية مع المدخلات المحلية من `cmd.exe` و `PowerShell` باستخدام ميزة تسوية الحجج (Argument Normalization) في Rust.
