# rust-logger

การนำคำสั่ง `logger` มาตรฐาน UNIX มาใช้ในภาษา Rust ซึ่งออกแบบมาเพื่อการใช้งานที่ปลอดภัยและเชื่อถือได้ในสภาพแวดล้อม Windows (Command Prompt / PowerShell) โดยจะแปลงข้อมูลนำเข้าจากการเข้ารหัสท้องถิ่น (Shift-JIS/UTF-16) เป็น UTF-8 โดยอัตโนมัติ และส่งไปยังเซิร์ฟเวอร์ Syslog

เครื่องมือนี้ได้รับการพัฒนาเพื่อให้ทำงานร่วมกับ **[vlt-syslogd](https://github.com/veltrea/vlt-syslogd)** ได้อย่างราบรื่น ซึ่งเป็นเซิร์ฟเวอร์ Syslog บน Windows ที่รองรับ UTF-8 และแสดงผลตัวอักษรหลายภาษาได้อย่างถูกต้อง

## คุณสมบัติ

- **ความเข้ากันได้กับ UNIX `logger`**: รองรับตัวเลือกมาตรฐาน เช่น `-n`, `-P`, และ `-p`
- **รองรับ Windows อย่างเต็มรูปแบบ**: จัดการข้อมูลนำเข้าจาก `cmd.exe` (Shift-JIS) และ `PowerShell` (UTF-16) ได้อย่างถูกต้อง
- **ไบนารีเดียว**: ทำงานเป็นไฟล์เรียกใช้งานแบบสแตนด์อโลนโดยไม่มีส่วนประกอบเสริมอื่นๆ

## เอกสารประกอบ

## การติดตั้ง

ดาวน์โหลด `rust-logger.exe` จากหน้า Releases และวางไว้ในไดเรกทอรีที่รวมอยู่ใน PATH ของระบบ

## การใช้งาน

การใช้งานพื้นฐานเหมือนกับคำสั่ง `logger` ของ UNIX ทุกประการ

```powershell
# การใช้งานพื้นฐาน (ลำดับความสำคัญเริ่มต้นคือ user.info)
rust-logger -n 127.0.0.1 -P 514 "เนื้อหาข้อความบันทึก"

# การระบุลำดับความสำคัญและแท็ก
rust-logger -n 192.0.2.10 -p local0.warn -t MyBatchApp "คำเตือน: กระบวนการล้มเหลว"
```

### ตัวเลือก

| ตัวเลือก | ตัวย่อ | คำอธิบาย | ค่าเริ่มต้น |
| :--- | :--- | :--- | :--- |
| `--server` | `-n` | **[จำเป็น]** ชื่อโฮสต์หรือ IP ของเซิร์ฟเวอร์ Syslog | - |
| `--port` | `-P` | หมายเลขพอร์ตปลายทาง | 514 |
| `--priority` | `-p` | ลำดับความสำคัญในรูปแบบ `facility.level` | `user.info` |
| `--tag` | `-t` | แท็ก (ตัวระบุ) | `rust-logger` |
| `--encoding` | - | การเข้ารหัสผลลัพธ์ (`utf-8`, `shift_jis`, ฯลฯ) | `utf-8` |
| `[MESSAGE]` | - | ข้อความบันทึก (ที่ส่วนท้ายของอาร์กิวเมนต์) | - |

## บันทึกการเผยแพร่

### การแก้ไขการรองรับหลายภาษา RFC 5424 (07/02/2026)
แก้ไขข้อผิดพลาดในการนำไปใช้งานที่เกี่ยวข้องกับข้อกำหนด RFC 5424:
- **รูปแบบฟิลด์ MSG**: เพิ่ม BOM ลงในส่วนเริ่มต้นของฟิลด์ `MSG` สำหรับรูปแบบ `MSG-UTF8` ได้อย่างถูกต้อง
- **การตรวจจับการเข้ารหัสอัตโนมัติ**: กำหนดโครงสร้างแพ็กเก็ตเป็น `MSG-UTF8` (มี BOM) สำหรับ UTF-8 และ `MSG-ANY` (ไม่มี BOM) สำหรับการเข้ารหัสอื่นๆ
- **การรวมเข้ากับ Windows**: ปรับปรุงโครงสร้างภายในเพื่อจัดการข้อมูลนำเข้าจาก `cmd.exe` และ `PowerShell` ได้อย่างโปร่งใสโดยใช้การทำให้พารามิเตอร์เป็นมาตรฐานของ Rust
