# คู่มือผู้ใช้ rust-logger

`rust-logger` เป็นเครื่องมือที่จำลองการทำงานของคำสั่ง `logger` มาตรฐาน UNIX บน Windows พร้อมทั้งปรับปรุงการรองรับสภาพแวดล้อมภาษาญี่ปุ่น ใช้สำหรับส่งข้อความไปยังเซิร์ฟเวอร์ Syslog จากสคริปต์และแอปพลิเคชันต่างๆ บน Windows

---

## 1. Syslog คืออะไร?
Syslog เป็นโปรโตคอลมาตรฐานสำหรับการส่งต่อข้อความบันทึก (log) ผ่านเครือข่าย
โดยทั่วไปจะใช้ร่วมกันระหว่างเครื่องมือฝั่งผู้ส่ง (เช่น `rust-logger`) และเซิร์ฟเวอร์ฝั่งผู้รับ/จัดเก็บ (เช่น `vlt-syslogd`)

### องค์ประกอบของข้อความ
นอกจากเนื้อหาหลักแล้ว ข้อความ Syslog ยังประกอบด้วยข้อมูลต่อไปนี้:
- **Priority (ลำดับความสำคัญ)**: ความสำคัญของข้อความ ระบุในรูปแบบ `facility.level` (เช่น `user.info`)
- **Tag (แท็ก)**: ตัวระบุว่าแอปพลิเคชันใดเป็นผู้สร้างบันทึก (เช่น `web-server`)
- **Timestamp (เวลา)**: วันที่และเวลาที่บันทึกถูกสร้างขึ้น
- **Hostname (ชื่อโฮสต์)**: ชื่อของเครื่องที่ส่งบันทึก

---

## 2. การใช้งานพื้นฐาน
คุณสามารถส่งข้อความได้ง่ายๆ โดยการเพิ่มข้อความไปที่ท้ายคำสั่ง

### การรันแบบพื้นฐาน
```cmd
rust-logger -n 127.0.0.1 "ข้อความทดสอบ"
```

### ตัวอย่างการใช้ Priority (-p)
การระบุลำดับความสำคัญให้เหมาะสมกับสถานการณ์เป็นสิ่งสำคัญ เพื่อให้สามารถตั้งค่าการกรองและการแจ้งเตือนที่มีประสิทธิภาพบนฝั่งเซิร์ฟเวอร์ Syslog ได้

| สถานการณ์ | ตัวอย่างคำสั่งที่แนะนำ | จุดประสงค์ |
| :--- | :--- | :--- |
| **บันทึกการทำงานปกติ** | `-p user.info` | การบันทึกปกติ เช่น "เริ่ม..." หรือ "เสร็จสิ้น..." |
| **ต้องใส่ใจ** | `-p user.warning` | "เกิดการลองใหม่", "พื้นที่ดิสก์เหลือน้อย" เป็นต้น |
| **ข้อผิดพลาดเล็กน้อย** | `-p user.err` | ความล้มเหลว เช่น "ไม่สามารถประมวลผลบางไฟล์ได้" |
| **ข้อผิดพลาดร้ายแรง** | `-p user.crit` | สถานการณ์วิกฤต เช่น "ไม่สามารถเชื่อมต่อฐานข้อมูลได้" |
| **ประกาศสำคัญ** | `-p user.notice` | บันทึกสำคัญที่ไม่ใช่ข้อผิดพลาด เช่น "การกำหนดค่ามีการเปลี่ยนแปลง" |
| **เอาต์พุตสำหรับการดีบัก** | `-p user.debug` | เอาต์พุตรายละเอียด เช่น เนื้อหาตัวแปรระหว่างการพัฒนาสคริปต์ |

### ตัวเลือกที่ใช้บ่อย
- `-n [ชื่อโฮสต์]`: เซิร์ฟเวอร์ปลายทาง (จำเป็น)
- `-p [ลำดับความสำคัญ]`: `user.notice`, `local0.err` ฯลฯ (ค่าเริ่มต้น: `user.info`)
- `-t [แท็ก]`: ชื่อแอปพลิเคชัน ฯลฯ (ค่าเริ่มต้น: `rust-logger`)

## 3. ตัวอย่างการใช้งานจริง

### การใช้ใน Batch Files (.bat)
มีประโยชน์สำหรับการแจ้งเตือนเมื่อเริ่ม/จบสคริปต์ หรือเมื่อเกิดข้อผิดพลาด
```batch
@echo off
set SERVER=192.0.2.10
rust-logger -n %SERVER% -t "BackupScript" "เริ่มกระบวนการสำรองข้อมูล"

copy C:\data D:\backup
if %ERRORLEVEL% NEQ 0 (
    rust-logger -n %SERVER% -p local0.err -t "BackupScript" "ข้อผิดพลาด: สำรองข้อมูลล้มเหลว"
) else (
    rust-logger -n %SERVER% -t "BackupScript" "สำรองข้อมูลเสร็จสิ้น"
)
```

### การใช้ใน PowerShell (.ps1)
ใน PowerShell แนะนำให้ใส่ "มาตรการแก้ไข Mojibake" ตามที่อธิบายด้านล่างไว้ที่ส่วนต้นของสคริปต์
```powershell
$Logger = "rust-logger.exe"
$Server = "127.0.0.1"

# มาตรการแก้ไข Mojibake (จำเป็น)
$OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

& $Logger -n $Server -t "PS-Script" "การแจ้งเตือนทดสอบจาก PowerShell"
```

## 4. การแก้ไขปัญหา: การแก้ปัญหา Mojibake (ตัวอักษรเพี้ยน)

เมื่อจัดการกับภาษาญี่ปุ่น (หรือตัวอักษรแบบมัลติไบต์) บน Windows โปรดระวังจุดต่อไปนี้

### หากเกิด Mojibake ใน PowerShell
PowerShell 5.1 มักจะทำให้เกิดตัวอักษรเพี้ยนเมื่อส่งอาร์กิวเมนต์ไปยังคำสั่งภายนอก
1.  บันทึกสคริปต์ด้วย **UTF-8 with BOM**
2.  ตั้งค่าการเข้ารหัสอย่างชัดเจนภายในสคริปต์ (ดูตัวอย่าง PowerShell ด้านบน)

### หากเกิด Mojibake ใน Command Prompt
`rust-logger` จะตรวจสอบและประมวลผลอินพุตโดยอัตโนมัติแม้ว่าจะเป็น Shift-JIS (CP932) แต่หากการแสดงผลผิดเพี้ยน ให้เปลี่ยนรหัสหน้า (code page) เป็น UTF-8 ชั่วคราว
```cmd
chcp 65001
```

### หากเกิด Mojibake ที่ปลายทาง
หากเซิร์ฟเวอร์ Syslog ปลายทางต้องการการเข้ารหัสเฉพาะ (เช่น Shift-JIS) ให้ใช้ตัวเลือก `--encoding`
```cmd
rust-logger -n 127.0.0.1 --encoding shift_jis "ข้อความภาษาญี่ปุ่น"
```

## 5. อ้างอิง Priority (Level และ Facility)

| ระดับ (Severity) | คำอธิบาย |
| :--- | :--- |
| `emerg`, `panic` | ระบบไม่สามารถใช้งานได้ (ความสำคัญสูงสุด) |
| `alert` | ต้องดำเนินการทันที |
| `crit` | ภาวะวิกฤต |
| `err`, `error` | ภาวะข้อผิดพลาด |
| `warning`, `warn` | ภาวะเตือน |
| `notice` | ภาวะปกติแต่สำคัญ |
| `info` | ข้อความข้อมูล |
| `debug` | ข้อความระดับดีบัก |
