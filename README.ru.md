# rust-logger

Реализация стандартной команды UNIX `logger` на языке Rust, разработанная для безопасного и надежного использования в среде Windows (Командная строка / PowerShell). Она автоматически преобразует ввод из локальных кодировок (Shift-JIS/UTF-16) в UTF-8 и отправляет его на Syslog-сервер.

Этот инструмент был разработан для бесшовной работы с **[vlt-syslogd](https://github.com/veltrea/vlt-syslogd)** — Syslog-сервером для Windows, который поддерживает UTF-8 и корректно отображает многоязычные символы.

## Функции

- **Совместимость с UNIX `logger`**: Поддержка стандартных опций, таких как `-n`, `-P` и `-p`.
- **Полная поддержка Windows**: Корректная обработка ввода из `cmd.exe` (Shift-JIS) и `PowerShell` (UTF-16).
- **Один бинарный файл**: Работает как автономный исполняемый файл без дополнительных зависимостей.

## Установка

Загрузите `rust-logger.exe` со страницы Releases и поместите его в каталог, включенный в системный PATH.

## Использование

Базовое использование идентично команде `logger` в UNIX.

```powershell
# Базовое использование (приоритет по умолчанию — user.info)
rust-logger -n 127.0.0.1 -P 514 "Текст сообщения лога"

# Указание приоритета и тега
rust-logger -n 192.0.2.10 -p local0.warn -t MyBatchApp "Предупреждение: процесс завершился ошибкой"
```

### Параметры

| Параметр | Сокращение | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `--server` | `-n` | **[Обязательно]** Имя хоста или IP-адрес Syslog-сервера | - |
| `--port` | `-P` | Номер порта назначения | 514 |
| `--priority` | `-p` | Приоритет в формате `facility.level` | `user.info` |
| `--tag` | `-t` | Тег (идентификатор) | `rust-logger` |
| `--encoding` | - | Кодировка вывода (`utf-8`, `shift_jis` и т. д.) | `utf-8` |
| `[MESSAGE]` | - | Сообщение лога (в конце аргументов) | - |

## Заметки к релизу

### Исправление поддержки многоязычности в RFC 5424 (07.02.2026)
Исправлены ошибки реализации, связанные со спецификацией RFC 5424:
- **Формат поля MSG**: Корректно добавлен BOM в начало поля `MSG` для формата `MSG-UTF8`.
- **Автоматическое определение кодировки**: Структура пакета настроена как `MSG-UTF8` (с BOM) для UTF-8 и `MSG-ANY` (без BOM) для остальных кодировок.
- **Интеграция с Windows**: Усовершенствована внутренняя структура для прозрачной обработки локализованного ввода из `cmd.exe` и `PowerShell` с использованием нормализации аргументов Rust.
